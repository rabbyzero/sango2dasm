## Disassembly notes

- Country index order in the ROM is **not** this map's layout; it is the
  province id order in [../province_data.md](../province_data.md)
  (0 = 遼東 … 29 = 永昌), which roughly runs north-east → south-west.
- Province name strings live at PRG `$21A1A` (bank `$30` `$9A1A`, 8 bytes per
  entry); the 32-byte starting records live at PRG `$20C00` (bank `$30`
  `$8C00`) and are copied to SRAM `$6000` by `SramInit`.
- 空白地 (unclaimed) countries can be taken by 武将の移動 without war; they are
  the records whose `+0` owner nibble is `7`.
