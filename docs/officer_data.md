# Officer data extracted from the ROM

All 237 officers with their katakana name (as stored in the
ROM), simplified-Chinese name, and starting data, read
directly out of the iNES image by
`tools/extract_officer_data.py`.

* PRG 256 KB, CHR 256 KB, mapper 19 (Namco 163)
* names: PRG `$2101A`, 10 bytes/entry (CPU `$901A`, bank `$30`)
* data: PRG `$22000`, 12 bytes/record (CPU `$8000`, bank `$31`)

## Record layout

The master record is the seed image of the officer's SRAM
record at `id * 12 + $63C0`, i.e. the new-game starting
state. Column names use the canonical semantic English
terms from `docs/manual_kb/terminology.md`.

| Offset | Field | Notes |
|---|---|---|
| `+0` | 体力 Vitality | 1-100 |
| `+1` | 武力 Might | 1-100 |
| `+2` | 知力 Intelligence | 1-100 |
| `+3` | 忠誠度 Loyalty | 100 = playable ruler |
| `+4` | 人徳 Virtue | 1-100 |
| `+5` | - | always 0 in ROM (runtime field) |
| `+6/+7` | 経験値 Experience | 16-bit LE; 0/1000/2000/3500/5000 |
| `+8/+9` | 兵数 TroopCount | 16-bit LE; non-zero only for officers on the map at the 189 start |
| `+10` | 武器 Weapon / 防具 Armor | bits 0-4 weapon, bits 5-7 armor |
| `+11` | レベル OfficerLevel / 軍の属性 ArmyAffinity | bits 4-7 level (0-based), bits 0-3 affinity |

軍の属性 / ArmyAffinity (low nibble of `+11`) only ever takes
six values, in pairs: `1`/`2` = 平軍 PlainsArmy, `5`/`6` = 山軍
MountainArmy, `9`/`10` = 水軍 NavalArmy. The affinity itself
is `(n - 1) / 4`; what distinguishes the two values within
each pair is not yet known.

### Notes

* Records 237-239 exist in the 240-slot array but hold
  unrelated bytes, which is why the officer count is 237.
* Experience only ever takes the five values that mark a
  level boundary, so it is redundant with the level nibble -
  except for id 71 侯成, who has 1000 experience but a level
  nibble of 0. That looks like a data-entry slip in the
  original ROM.
* Starting province and appearance year are *not* in this
  record; they live in a separate scenario table.
