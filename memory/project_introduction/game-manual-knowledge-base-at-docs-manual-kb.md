## Content

The scanned original Japanese user manual (res/manual_jpn/Sangokushi2-NN.jpg, 37 two-page spreads, manual pages ~1-71) has been transcribed into a structured knowledge base at docs/manual_kb/ (README.md is the index with a scan-to-page map; 14 topic files plus terminology.md). terminology.md is the consolidated semantic English glossary (Japanese -> reading -> English term) and is the authoritative naming reference, aligned with the project's PascalCase semantic convention (e.g. 計略 -> Stratagem, 陣形 -> Formation, 一騎討ち -> Duel; NOT romaji-based names). It documents modes (戦略/戦術/戦闘/一騎討ち), strategy-mode command groups (城/軍隊/倉/町), tactical commands, the 計略 stratagem list, battle commands and 戦術 tactics list, formations, duel commands, officer/country stats, events, 7 ruler profiles, and the 30-country map. Entries marked (?) are uncertain readings. PROJECT.md links to this KB.
