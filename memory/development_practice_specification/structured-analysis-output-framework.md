# Structured Analysis Output Framework

- **Category:** development_practice_specification
- **Memory ID:** a1ee1788-9edf-4d39-86c3-9787bcfc2ff5
- **Keywords:** analysis structure, reverse engineering, documentation
- **Usage scenarios:**
  - Producing standardized analysis reports
  - Ensuring completeness in reverse-engineering tasks
  - Reviewing analysis for missing components

## Content

Analysis output must follow a 10-part structure: 1) Header (address, entry, caller), 2) High-level purpose, 3) Initialization, 4) Main loop breakdown, 5) Sub-routines, 6) Command dispatch table, 7) RAM layout, 8) Data tables, 9) Hardware interaction, 10) Summary.
