# Use symbolic proc names in dispatch tables

- **Category:** development_practice_specification
- **Memory ID:** 31420274-2c9f-4198-b01e-758cc16132f1
- **Keywords:** symbolic names, dispatch table, proc names

## Content

Dispatch tables like NmiDispatchTable should use symbolic proc names (e.g., NmiState0_Idle) instead of raw hexadecimal addresses to improve code readability and maintainability.
