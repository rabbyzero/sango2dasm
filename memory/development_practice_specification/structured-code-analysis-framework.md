# Structured code analysis framework

- **Category:** development_practice_specification
- **Memory ID:** 76b42d87-9757-411e-a53c-5b2616f0d9b1
- **Keywords:** code analysis, reverse engineering, structured framework
- **Usage scenarios:**
  - Analyzing disassembled routines with comprehensive 10-part coverage
  - Onboarding developers to reverse-engineering standards for battle routines
  - Standardizing documentation for complex sound engine regions

## Content

Code analysis should follow a structured 10-part framework:
1. Header (address range, entry, caller)
2. High-level purpose
3. Initialization steps
4. Main loop breakdown (table format)
5. Sub-routines overview
6. Command dispatch table (if applicable)
7. RAM layout (struct offsets and fields)
8. Data tables summary
9. Hardware interaction details
10. Summary paragraph
