Bank $31 (physical prg_11.bin) $9BA4-$9C57 `ProvinceCityTileTable` (data_11.asm, generated by tools/gen_data_bank_asm.py): 30 rows x 6 bytes = three ordered (X,Y) tile pairs per province $050E — the facility locations of the province's tactical-mode battlefield. Fixed slot order: +0/+1 House 民家 (rice market), +2/+3 Armory 武器屋, +4/+5 Hospital 病院. Pair unused when X has bit7 set (readers BMI/BPL; authored padding $FF $FF). Coords are tiles of the 32x32 battlefield (observed $01-$1D); march readers normalize Y >= $10 by Y-1 (map gap row). Evidence (direct): arriving on pair N stores slot index N into $0470 and enters phase $09; State9_RouteNextAction (prg_08_09 $C7C8) dispatches route_mode $0470 — $00 -> State0 rice-buy panel $C0D5, $01 -> State5 armory grid $C4B8, else -> State3 vitality check $C3E3 -> State4 hospital heal $C3E9 (50 gold, vitality clamped at the ROM base record) — so slot order is House/Armory/Hospital; Action_BuyRice/Action_RestoreHP march to slots 0/2 and DrawStratagemTargetMarkers ($D24D) draws city-target markers at all three pairs. Occupancy: House 16, Armory 21, Hospital 25 provinces; 11 all three; no empty row. House slot != strategy-layer 商店 flag (青州 id3 market-but-no-House, 襄阳 id22 reverse).
