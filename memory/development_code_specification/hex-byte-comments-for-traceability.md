# Hex byte comments for traceability

- **Category:** development_code_specification
- **Memory ID:** 96f363e2-8630-4732-8ec5-5f18a5ba26ea
- **Keywords:** hex comments, traceability, raw bytes

## Content

Hexadecimal values in comments at memory locations like $C000 must include raw hex bytes for traceability against the binary, ensuring alignment with actual assembled output.
