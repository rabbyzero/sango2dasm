# CallbackDispatcher naming consistency

- **Category:** development_code_specification
- **Memory ID:** 02772ee5-5b45-4a3e-b22f-e271f65740de
- **Keywords:** CallbackDispatcher, naming consistency, procedure rename

## Content

The inline dispatch procedure previously named 'Loc_B517' or 'InlineDispatch' has been renamed to 'CallbackDispatcher' to maintain naming consistency with the equivalent implementation in bank $1F (B1F_CallbackDispatcher). This ensures uniform naming for identical mechanisms across different code banks.
